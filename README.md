# Token Monitor

macOS 屏幕常驻小窗，显示 **Codex 与 Claude Code 的编程订阅剩余额度和重置时间**。品牌图标使用原版结形和放射形的透明矢量，没有图标底框。原生毛玻璃背景，可拖动、隐藏，或收起为屏幕边缘的 48 像素缩略窗。

[下载 DMG](https://github.com/chenjinfu00/token-monitor/raw/refs/heads/main/downloads/v0.9.0/Token-Monitor-0.9.0-macos-universal.dmg) · [安装与登录](#下载与安装) · [MIT 许可证](LICENSE)

显示的是服务返回的额度百分比，不是精确 token 数，也不覆盖普通 ChatGPT 网页聊天的所有用量。需要 macOS 13 或更新版本。

## 下载与安装

1. 下载 [DMG 安装包](https://github.com/chenjinfu00/token-monitor/raw/refs/heads/main/downloads/v0.9.0/Token-Monitor-0.9.0-macos-universal.dmg) 或 [ZIP 安装包](https://github.com/chenjinfu00/token-monitor/raw/refs/heads/main/downloads/v0.9.0/Token-Monitor-0.9.0-macos-universal.zip)。两者同时支持 Apple Silicon 与 Intel。
2. ZIP 解压后，将 **Token Monitor.app** 拖到 Finder 的“应用程序”。如果下载的是 DMG，打开后将应用拖到“应用程序”。
3. 从“应用程序”双击 **Token Monitor**。应用会显示悬浮窗和菜单栏双行额度图标，不显示 Dock 图标。悬停在图标上可查看监控说明。

当前版本使用 ad-hoc 签名，尚未通过 Apple 公证。首次打开若提示开发者无法验证，确认下载来源后，先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”，按提示确认。详见 [Apple 的打开说明](https://support.apple.com/en-us/102445)。

应用本身不需要 API key，但需要本机官方工具已有的订阅登录：

- **Codex**：安装并登录 [官方 Codex](https://learn.chatgpt.com/docs/codex/cli)。应用可发现常见位置的 Codex CLI 和 Codex 桌面应用内置 CLI；API key 登录不一定提供订阅额度。
- **Claude**：安装并登录 [官方 Claude Code CLI](https://code.claude.com/docs/en/quickstart)，使用 Claude 订阅认证。Claude 桌面应用和终端 CLI 的登录会话可能不同；只登录桌面应用不足以保证这里可以查询。

首次设置可以按下面的顺序完成；官方工具若已经装好并登录，只需打开 Token Monitor：

| 步骤 | 操作 |
| --- | --- |
| 1 | 安装 Token Monitor，并移入“应用程序”。 |
| 2 | 在官方 Codex CLI 执行 `codex login`，选择 ChatGPT 账户并完成浏览器授权；也可使用应用能找到的官方桌面内置 CLI。 |
| 3 | 在官方 Claude Code CLI 执行 `claude auth login --claudeai`，完成订阅账户授权；也可用 Token Monitor 菜单栏的登录入口。 |
| 4 | 打开 Token Monitor，等待首次同步；之后通常每分钟更新。 |

仅在 ChatGPT 或 Claude 网页登录不会为本工具建立本机 CLI 会话。需要账户本身具备对应的编程工具使用权限；API 付费账户的余额不属于这里监控的订阅额度。官方工具由各服务提供，本安装包不内置它们，也不会自动替用户安装。

无需在 Token Monitor 中重复登录已有的有效账户。未安装、未登录或当前官方工具不支持读取额度时，会显示等待或错误说明；点击对应的 **i** 查看详情。需要重新登录 Claude Code 时，可从菜单栏选择“登录终端 Claude Code”，在官方登录页面自行完成授权。

## 常见情况

| 看到的状态 | 如何处理 |
| --- | --- |
| 未找到 Codex / Claude Code | 先安装对应官方工具；应用可发现 Homebrew 和 `~/.local/bin` 等常见安装位置。 |
| 未登录或授权过期 | 在官方工具重新登录，再点击“立即同步”；浏览器网页登录不能替代 CLI 登录。 |
| Claude 时间“待定” | 服务没有返回重置时刻，保持未知并继续同步，无需重新登录。 |
| 超时、离线或服务限流 | 检查本机网络；应用保留最后一次确认的数据并自动重试，限流时退避。 |
| 只显示一个服务 | 两家独立查询，先配置另一家的官方工具和订阅认证即可。 |
| 系统提示开发者无法验证 | 参照上面的 Apple 首次打开说明；当前安装包尚未公证。 |

卸载时退出应用，再从“应用程序”移走 Token Monitor。若启用过可选 Claude 状态栏采集，可先在终端运行下面的命令解除连接；默认主动查询模式不修改 Claude 设置：

```sh
python3 "$HOME/.claude/token-monitor/bridge.py" uninstall
```

## 日常使用

- 展开窗宽 340 点，紧凑模式为 320 点。左侧排列日期与倒计时，右侧进度条整体垂直居中；普通额度与公共预测条使用相同的纵向间隔。
- 左上依次为退出、隐藏、尺寸切换和刷新，右上保留 Codex / Claude 品牌图案。拖动服务标题或顶部留白移动窗口，位置会保存；双击标题或留白循环切换窗口尺寸。**i** 和日期可点击查看同步状态、周期及重置详情。
- 点击左上刷新按钮，或菜单栏“立即同步”，尝试立即查询。正常每 60 秒同步一次，电脑唤醒后也会尝试更新；倒计时每秒变化。
- 尺寸按钮按“缩略 → 中等额度窗 → 完整图表 → 缩略”循环；也可通过菜单栏“收起到屏幕边缘”直接收起。缩略窗宽 **48 像素**，Codex 在上、Claude 在下，竖排显示图标、剩余百分比和一行倒计时。满一天用一位小数天数（如 **5.2d**），不足一天按小时、分钟或秒显示。每家选剩余额度最少的整体周期，百分比与倒计时来自同一周期。双击缩略窗展开，悬停可查看详情。收起期间继续同步，收起状态在重启后保留。
- 缩略窗可按住拖动，拖到屏幕上方时自动横排，靠近左右边缘时竖排；位置和方向会保存。双击展开，拖动后不会误展开。小时数超过 10h 时显示整数，10h 以内保留一位小数。
- 展开窗口靠着当前缩略窗出现，并保持在当前屏幕内；三种尺寸切换有平滑过渡，开启系统“减少动态效果”时使用简化过渡。
- 缩略窗末尾保留可点击的地球图标，打开 Codex Resets 公共重置信息；顶部横排时位于最右侧。
- 应用使用单实例保护；再次打开会显示已有窗口，不会再启动一份后台采集。隐藏或收缩状态下重新打开，会恢复对应模式。
- 窗口保持在普通应用及浮动窗口之上，切换应用或桌面时恢复前景顺序，不抢走键盘焦点。
- “隐藏小窗口”隐藏展开窗和缩略窗，继续后台同步。“显示小窗口”恢复上次模式；应用已隐藏时再次双击打开也会恢复显示。缩略窗已显示时，再次打开应用不会强制展开。
- 菜单栏“紧凑 / 完整显示”切换显示周期数量；“退出 Token Monitor”停止后台同步并退出。可在 macOS“登录项”中添加应用，让它登录后自动打开。

**重置日期跟随 macOS 当前时区，并自动处理夏令时。** 主界面只显示月、日、时、分；详情中可查看时区。服务没有提供 Claude 重置时间时，日期与倒计时显示“待定”；额度百分比照常显示，未知时间不绘制时间进度。

额度条与蓝色时间条都表示 **剩余百分比**。额度比剩余时间多超过 5 个百分点时为绿，少至少 15 个百分点时为红，其余为黄；未知、周期不明或已经结束时为灰。这只是均匀使用节奏的参照，不能用来推算剩余 token。

## 用量历史

点击左上尺寸按钮，或菜单栏“用量历史”，在同一个悬浮窗进入详细图表；尺寸按钮与双击空白处沿三种尺寸循环。缩略窗不显示尺寸按钮，双击进入中等额度窗。支持连续横向滚动的时间轴，可切换 Codex / Claude 和额度周期；日、周、月、年调整同屏时间跨度与曲线密度，不按日期分页。滚轮或触控板滚动查看过去，点击“现在”返回最新位置。移动鼠标或点击数据点可查看该段的最高已用比例、末次比例和观测时间。右上角的重置历史可跨图表时间范围查看各次重置前的已用比例；独立重置日志在确认额度回补时立即保存，重启后仍可查看。只有期限变化时不会计作额度重置。图表底部用紫色菱形标记观察到的额度恢复，蓝色菱形标记重置计划变化；点击标记可查看前后使用比例、前后重置期限及两次刷新的观察时间范围。真正的重置可能发生在这个范围内，观察时刻不等同于精确发生时刻。

日、周、月视图中的蓝色虚线从当前周期起点的 0% 连到官方下次重置的 100%，作为均匀使用额度的参考。有效且早于官方期限的 Codex 网站预测另绘紫色虚线，两线不会改变实际用量或官方期限；缺少可靠周期起点或预测时隐藏对应参考线。重置日期标记可点击定位，时间轴允许查看未来；“现在”始终保留当前时刻和实际用量在视区内。

年度视图按日历周绘制累计已用额度柱，可超过 **100%**；例如两次分别用掉 80% 后重置，累计为 160%。重置记录按观测到的周归档：每次回补计入重置前后已用比例的差额（归零时即重置前已用比例），并加上当前有效快照的已用比例。无有效记录的周留空。该统计来自已观测的额度百分比，不能换算精确 token 数，也无法还原停机期间未观察到的消耗或精确分摊到实际使用的周。

默认每 **15 分钟**保存一个时间段，每家服务的每个额度周期分别记录这段里**实际观察到的最高已用百分比**、末次百分比、同步次数、服务提供的重置时间，以及观察到的额度回补或期限变化。图中显示已用百分比，与实时小窗的剩余百分比互补；不能换算精确 token 数，也不是该段新增消耗的百分比。历史从启用记录后开始，之前的用量不会补造。

实时查询保持每分钟进行，观察结果在内存中合并，完成时间段后才写入磁盘。休眠、退出或查询失败期间不会补造样本，缺口和额度回补处不连接趋势线。较长视图按更大时间段取峰值，原始记录保留。期限变化只表示官方计划变化，不等同于账户实际恢复；回补以实际看到的使用比例下降为依据。

主窗口底部的设置可暂停记录，把保存间隔设为 **1、5、15、30 分钟或 1 小时**，查看历史文件占用，并清理所选年月日之前的记录。清理前会再次确认截止日期，保留当天和之后的数据；跨越截止时刻的整个记录区间也会保留。修改间隔只影响之后的记录，现有历史保留。暂停、改设置和正常退出会保存尚未完成的时间段；强制结束应用或断电可能丢失当前未保存的一段。日期清理只处理本应用历史，不影响登录、实时额度、Claude 采集配置或窗口偏好。

## 数据来源与新鲜度

**Codex** 通过官方本机 CLI 的 `account/rateLimits/read` 读取账户额度与重置时间，支持服务返回的当前、每周和多个额度类别。额度下降后接近全额恢复且期限不变时，应用以本机观察时刻重建比较起点；公共网站消息不会修改账户期限或确认账户恢复。该比较起点在应用运行期间跟踪，重启后根据官方周期重新推算。

**Claude 主动查询**默认每分钟启动官方 CLI，仅发送 `initialize` 和 `get_usage` 控制消息，不提交模型问题。查询进程使用 safe mode、禁用内置工具和非策略 MCP；组织管理策略仍然生效。只有同时取得可解析额度和服务端成功请求标志，才更新同步时间。超时、缓存无法确认或其他失败会保留上次确认值并显示原因；限流会自动退避。已验证 Claude Code **2.1.224** 的 Team 订阅查询，但控制协议及诊断标志可能随官方版本变化，不保证所有版本、计划或网关均支持。未返回的周期不会补成 0%。

旧数据的更新时间保留，超过五分钟会标记较早快照。周期到期后显示等待更新，不会自动假设额度已经恢复。离线状态下仍可显示上次数据及其年龄。

**公共重置信息**来自第三方 [Codex Resets 中文站](https://codex-resets.com/zh-CN)，通过其 [公开 API](https://codex-resets.com/api/docs) 的 `/api/v1/status` 查询，无需 key；每分钟使用 ETag 条件请求，处理缓存年龄与限流。来源链接始终显示。该网站与 OpenAI 无关联，其记录、备用重置机会及概率不能证明你的账户已恢复，应用也不会自动兑换重置机会。

紫色网站时间条仅在接口给出**常规重置公告和明确、有效的未来 `scheduled_for`** 时显示，从公告时刻到目标时刻展示剩余时间。没有明确时间、公告已到期、网站数据过旧或查询失败时完全隐藏。历史平均、概率、自然语言时间范围、监测过期时间和备用重置发放均不会生成时间条。

## 可选：Claude 状态栏推送

菜单栏“Claude 读取方式”可切换“主动查询（每分钟）”与“状态栏推送”。主动查询无需安装采集器，也不读取 Claude 桌面历史文件。

状态栏模式需要 Python 3，以及“启用终端 Claude 额度采集”。这会在 `~/.claude/settings.json` 添加可还原采集器，备份原设置，保留其他字段和已有 statusline 的执行。它只采集实际收到的 `rate_limits`，每两秒读取本地快照；这是响应驱动的来源，状态栏定时刷新不能使额度变新。官方 [statusline 文档](https://code.claude.com/docs/en/statusline) 当前列出 Pro/Max 和指定 gateway；其他计划是否返回额度以实际回调为准。

正常 Claude Code 回复后才可能收到额度。应用区分尚无回调、有回调但无额度、已收到额度；其他设备或空闲会话的用量可能要等下一次响应才能反映。主动查询与状态栏快照不会拼接。相同未过期窗口内的较低使用量会保守保留原较高值，重复回调不刷新快照时间；特殊的官方修正可能要等窗口重置才反映。此模式按单账户使用设计，多账户不要共用快照目录。

从源码目录手动连接、检查或解除连接：

```sh
python3 tools/claude_bridge.py install
python3 tools/claude_bridge.py --status
python3 tools/claude_bridge.py uninstall
```

解除连接只还原仍属于本工具的 statusline，保留用户之后修改的其他字段或替换的 statusline。安装的脚本及设置备份保留在 `~/.claude/token-monitor/`；备份是原配置的副本，应和原配置一样保管。脚本独立于应用位置，移动或删除应用不会自动解除连接。

## 隐私与本地文件

主动查询通过官方 CLI 完成认证及刷新，不自行提取认证 token。不会发送模型请求，不上传对话或额度给公共重置网站。Claude 查询诊断只在进程内识别白名单成功/失败标志，原日志不写入磁盘或展示。

用量历史仅保存在 `~/Library/Application Support/Token Monitor/History/`，按月保存额度数字、观测和重置信息；不会保存对话、密钥或账户标识，也不会上传。历史文件使用 `0600` 权限，可以在面板设置中查看占用和按日期清理。切换登录账户时建议先清空或暂停历史，避免在同一服务曲线上混合两个账户。

状态栏采集会写入以下私有文件，使用权限 `0600` 和原子替换；不保存对话、账户标识、密钥或完整 statusline 输入：

- `~/Library/Application Support/Token Monitor/claude-quota.json`：额度百分比、重置时间和原始接收时间。
- 同目录 `statusline-diagnostics.json`：回调、响应及额度字段是否存在等安全诊断。

启用状态栏时保存的设置备份包含原 `settings.json` 的完整内容；不要把这些本地配置、备份或快照加入公开仓库。原有 statusline 会继续执行，并收到原始输入，行为由用户自己的命令决定。

## 从源码构建

需要 macOS 13+、Apple Swift 工具链，以及用于桥接测试的 Python 3；无第三方 Swift 或 Python 依赖。

```sh
git clone https://github.com/chenjinfu00/token-monitor.git
cd token-monitor
zsh tools/test.sh
zsh build.sh
```

构建输出为 `dist/Token Monitor.app`，默认构建当前电脑的架构。构建 Intel + Apple Silicon 通用应用使用 `zsh build.sh --universal`；生成可下载的 ZIP、DMG 和校验文件使用 `zsh tools/package-release.sh`。下载发行包不需要 Swift 工具链。测试入口优先使用已有的 Anaconda Python，否则使用 `PATH` 中的 `python3`，不会安装依赖。测试只使用固定样例和临时目录，不访问账户、不发起模型请求，也不修改真实 Claude 设置。

当前安装包保存在 [`downloads/v0.9.0/`](downloads/v0.9.0/)，同目录提供 `SHA256SUMS.txt`。另提供 GitHub Actions 发行工作流：推送版本标签（如 `v0.9.0`）后测试、构建并上传到 Releases。主分支和 Pull Request 的独立检查只测试及构建，不发布安装包。当前没有自动更新，请从仓库下载新版本后替换应用。

校验单个下载文件时，在终端进入下载目录并运行：

```sh
shasum -a 256 Token-Monitor-0.9.0-macos-universal.dmg
```

将输出与同目录 `SHA256SUMS.txt` 的 DMG 那一行比较；ZIP 同理，只需检查自己下载的文件。安装包目录的 `BUILD_INFO.md` 记录源码提交、构建版本与架构。

可在本机手动检查官方额度读取；这些命令会实际查询当前官方 CLI 账户，只输出白名单额度摘要：

```sh
"dist/Token Monitor.app/Contents/MacOS/TokenMonitor" --probe
"dist/Token Monitor.app/Contents/MacOS/TokenMonitor" --claude-probe
```
